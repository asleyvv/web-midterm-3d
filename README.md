# TTG Marketplace — Browse and Community contribution

Open index.html after extracting the ZIP. No JavaScript is used or included. Bootstrap CSS is bundled in css/bootstrap.min.css; fonts have local system fallbacks.

## My contribution
- browse.html: six product cards laid out with CSS Grid, a product comparison table, a condition guide, and HTML details/summary for descriptions.
- community.html: community introduction, group cards using CSS Grid, an example events table, a photo, and house rules.
- css/pages.css: shared page and card styles, Flexbox alignment, relative/absolute product badges, tablet and mobile breakpoints.
- images/: three locally saved photos and SOURCES.txt with source links.
- index.html: photos and descriptive titles added to the existing featured cards.

## Team integration
The navigation includes index.html, browse.html, sell.html, community.html, about.html, and contact.html. Sell and Contact belong to other team members and are not included in this contribution. Those links will work once their files are added. The navbar wraps on mobile without scripts. The existing About FAQ displays its answers without JavaScript.

The original filenames were normalized: Index.html → index.html; About.html → about.html; Style.css → css/style.css; Resposive.css → css/responsive.css. Template.html remains the team's starter template.

## Defense
- CSS Grid creates responsive product/group columns: three on desktop, two on tablet, one on mobile.
- Bootstrap CSS row/col classes create the Community introduction layout.
- Flexbox aligns prices and navigation.
- Tables use caption, thead, tbody and scope for clear structure.
- Details/summary provides native HTML expansion, requiring no JavaScript.
- Product badges are absolutely positioned within relatively positioned image wrappers.
- Tables scroll inside their containers on small screens.

Listings, prices, and events are examples for the student project. Photos are illustrative. Buying, messaging and event registration are not implemented. Sell/Contact forms and publication remain part of the team's full project.
